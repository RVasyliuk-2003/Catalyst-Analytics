# React + TypeScript — шаблон проєкту

Базовий шаблон для створення вебзастосунків на **React, TypeScript і Vite**. Містить початкову конфігурацію та інструменти, які допомагають швидше розпочинати нові проєкти.

## Технології

- **React** — створення інтерфейсів користувача.
- **TypeScript** — типізація JavaScript і виявлення помилок під час розробки.
- **Vite** — запуск сервера розробки та збирання проєкту.
- **CSS Modules** — ізольовані стилі компонентів.
- **ESLint** — статичний аналіз коду.
- **Prettier** — автоматичне форматування коду.

## Початок роботи

### Встановлення

1. Встанови залежності:

   ```bash
   npm install
   ```

2. Запусти сервер розробки:

   ```bash
   npm run dev
   ```

## Доступні команди

| Команда                | Призначення                                        |
| ---------------------- | -------------------------------------------------- |
| `npm run dev`          | Запуск сервера розробки                            |
| `npm run build`        | Перевірка TypeScript і створення production-збірки |
| `npm run preview`      | Перегляд створеної production-збірки               |
| `npm run lint`         | Перевірка коду за допомогою ESLint                 |
| `npm run format`       | Автоматичне форматування файлів через Prettier     |
| `npm run format:check` | Перевірка форматування без змін файлів             |

Після значних змін рекомендується запускати:

```bash
npm run lint
npm run build
```

## Структура проєкту

```text
src/
├── assets/       # Зображення та інші ресурси
├── components/   # Повторно використовувані компоненти
├── pages/        # Сторінки застосунку
├── hooks/        # Власні React-хуки
├── types/        # Спільні типи TypeScript
├── App.tsx       # Кореневий компонент
├── App.module.css
├── index.css     # Глобальні стилі
└── main.tsx      # Точка входу застосунку
└── reset.css     # скидання дефолтних стилів


```

Деякі папки можуть бути відсутні на початку. Створюй їх у міру потреби.

## Змінні середовища

Файл `.env.example` містить приклад змінних середовища, які можуть знадобитися проєкту.

Щоб почати роботу з власними значеннями:

1. Створи файл `.env` у корені проєкту.
2. Скопіюй до нього потрібні змінні з `.env.example`.
3. Заміни прикладові значення на актуальні.

Приклад:

```env
VITE_API_URL=https://api.example.com
VITE_APP_NAME=My React App
```

Отримання значень у коді:

```ts
const apiUrl = import.meta.env.VITE_API_URL;
const appName = import.meta.env.VITE_APP_NAME;
```

**Безпека:** усі змінні з префіксом `VITE_`, використані в клієнтському коді, доступні користувачам браузера. Не зберігай у них паролі, приватні ключі, токени з підвищеними привілеями або інші секрети.

Не додавай реальний файл `.env` до Git. Для нових змінних оновлюй `.env.example`, використовуючи безпечні прикладові значення.

## Створення нового проєкту

Якщо цей репозиторій налаштовано як шаблон GitHub:

1. Відкрий його сторінку на GitHub.
2. Натисни **Use this template**.
3. Вибери **Create a new repository**.
4. Вкажи назву нового проєкту.
5. Створи репозиторій.
6. Клонуй його на комп'ютер і встанови залежності:

   ```bash
   npm install
   ```

7. Запусти проєкт:

   ```bash
   npm run dev
   ```

Після цього можна змінювати компоненти, стилі та конфігурацію відповідно до потреб нового застосунку.

## Принципи використання шаблону

- Використовуй TypeScript для типізації компонентів, функцій і даних.
- Зберігай стилі компонентів у CSS Modules, а глобальні стилі — в окремому файлі.
- Не встановлюй бібліотеки без конкретної потреби.
- Не додавай секрети до репозиторію.
- Перед публікацією змін перевіряй код і production-збірку.
- Підтримуй цей шаблон у робочому стані, щоб використовувати його в наступних проєктах.
